# CodeFox

AI co-builder focused on finishing real projects.

## Features
- Login (Supabase)
- Plan / Build / Review / Ship
- Multi-file + HTML preview
- Levels, XP, streaks, achievements
- Onboarding
- Mobile UI (ready for APK)
- PWA manifest

## Web
```bash
npm install
cp .env.example .env.local
npm run dev
```
